# Calculadora de Orçamento Habitacional

Projeto em Python para calcular a percentagem do aluguel em relação à renda mensal e validar o limite de 30%.

## 🚀 Funcionalidades
- Validação do limite de 30% do orçamento.
- Loop de repetição para múltiplos testes.
- Tratamento de resposta para encerramento (`n`, `nao`, `não`).

## 🛠️ Tecnologias
- Python 3
